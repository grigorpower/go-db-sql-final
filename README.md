# Описание проекта 

Проект представляет собой сервис для отслеживания посылок. Сервис реализует следующие функции:
1. Регистрация посылки.
2. Получение списка посылок клиента.
3. Изменение статуса посылки.
4. Изменение адреса доставки. 
5. Удаление посылки.

Информация о посылках хранится в БД `tracker.db`. Посылка может быть зарегистрирована, отправлена или доставлена. При регистрации посылки создаётся новая запись в БД. У только что зарегистрированной посылки статус «зарегистрирована». Трек-номер посылки равен её идентификатору в таблице. Если посылка в статусе «зарегистрирована», можно изменить адрес доставки или удалить посылку.

В файле `main.go` содержится код, отвечающий за подключение к базе данных SQLite. Примеры реализация сервиса отслеживания посылок, обработка и трансляция ошибок, логирование операций. 

В фалйе `parcel.go` содержатся методы структуры ParcelStore. Работа с SQLite базой данных. Выполнение CRUD операций

В файле `parcel_test.go` содержатся тесты.
